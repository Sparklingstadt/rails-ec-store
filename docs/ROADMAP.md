# v0.1.0以降の実装順序

v0.1.0はゲスト購入版のスナップショットです。次の機能を順に追加します。

1. 会員登録・ログイン・ログアウト: BCrypt、セッションの更新、認証の試行回数制限。
2. マイページ: 会員に紐づく注文・カート・お気に入り、お届け先の保存。ログイン時に現在のブラウザのゲストデータを引き継ぎます。
3. 管理者の商品管理: 権限分離、商品作成・編集、公開切り替え、在庫変更。注文済みの商品は削除せず非公開にします。
4. 注文管理: 受付・発送・キャンセル、所有者と管理者の操作制限、在庫を一度だけ戻す処理。
5. 検索拡張: 価格帯、在庫の有無、ページ切り替え。絞り込みと並び替えを組み合わせます。

実決済・外部メール送信・配送サービス連携はこの段階に含めません。アカウントや注文にはサンプル情報を使います。
